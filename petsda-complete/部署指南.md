# PETSDA 官网部署指南（无需 GitHub）

网站是纯静态站（HTML + CSS + 图片），不需要任何构建步骤。
总大小约 2.9 MB，共 14 个文件。

**当前线上预览地址**：https://acac78703ce1f2ac4.app.workbuddy.host

---

## 方案一：Netlify Drop（最推荐，零代码、零注册即可先试用）

**最快路径 —— 连账号都不用，拖一个文件夹 30 秒上线：**

1. 打开 https://app.netlify.com/drop
2. 把 `petsda` 文件夹（或解压后的内容）直接拖进浏览器页面
3. 立刻得到一个 `https://xxxx-xxxx.netlify.app` 的网址，可立即访问

**要长期保留 + 绑定自己域名，则需免费注册：**

1. 访问 https://app.netlify.com/signup
2. 选 **Email** 方式（不用 GitHub），填邮箱 + 密码
3. 收邮件点确认链接，完成注册（免费，无需信用卡）
4. 登录后再次拖拽上传 `petsda` 文件夹
5. 进入 Site settings → Domain management → Add custom domain，填你的域名
6. 按提示到域名服务商处添加 DNS 记录（Netlify 会给具体值），10 分钟~2 小时生效，HTTPS 自动配置

## 方案二：Cloudflare Pages（免费、全球 CDN 速度快）

1. 访问 https://dash.cloudflare.com/sign-up
2. 用 **Email** 注册（同样不需要 GitHub）
3. 登录后左侧菜单 → **Workers & Pages** → **Create** → **Pages** → **Upload assets**
4. 项目名填 `petsda`，把文件拖上去，点 **Deploy site**
5. 得到 `https://petsda.pages.dev` 网址
6. 绑定域名：项目内 **Custom domains** → 输入域名。若域名 DNS 也托管在 Cloudflare，一键完成

> 提示：Cloudflare 的 Drag & Drop 上传对文件夹层级有要求，确保 `index.html` 和 `assets/` 都在上传的根层级（本项目的 zip 解压后即是）。

---

## 方案三：Vercel

Vercel 现在主推 GitHub 集成，但**也可以用邮箱注册后走 CLI 上传**：

1. 访问 https://vercel.com/signup ，选 **Email**
2. 本机安装 Node.js 后，命令行执行：
   ```bash
   npm i -g vercel
   cd petsda
   vercel --prod
   ```
3. 按提示用邮箱验证登录，一路回车（Framework 选 Other，无需构建命令）

## 上线后必做的 3 件事

### 1. 替换亚马逊商品链接
目前所有按钮指向品牌搜索页 `https://www.amazon.com/s?k=PETSDA`。
拿到真实 ASIN 后，用文本编辑器打开 `index.html`，搜索替换：

| 产品 | 建议替换为 |
|---|---|
| PetFeeder T1 | `https://www.amazon.com/dp/你的ASIN` |
| PetFeeder W1 | 同上 |
| PetFeeder D1 | 同上 |
| PetFeeder W2 | 同上 |
| SmartCam C1 | 同上 |
| SmartCam C2 | 同上 |

替换后重新上传部署即可（Netlify / Cloudflare 支持直接拖拽覆盖更新）。

### 2. 核对评分数据
页面上「4.8 (2,300+)」等为示例数据，请按亚马逊后台真实评分与评论数修改。

### 3. 补充法务页面
已有 `privacy.html`（隐私政策）。建议再补：
- Terms of Service（服务条款）
- Shipping & Returns（配送与退货）
- Contact Us（联系页，含邮箱/表单）
